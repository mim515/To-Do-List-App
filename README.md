---

## Usage

1. Open the app via the live demo link or your local setup (see installation).  
2. In the “Add” input, type your task and press **Enter** or click add.  
3. Tasks appear below in a list.  
4. To delete a task, click the delete / trash icon next to it.  
5. (Optional) Add enhancements like mark-as-complete, editing, filtering, etc.
